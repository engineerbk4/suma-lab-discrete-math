    ANTES DE DEMOSTRAR

    Predice el siguiente sumando

    Los primeros bloqueos duran 1, 2 y 4 minutos. Ya suman 7. Para un cuarto episodio y un máximo de 5 minutos:

    min
    min
    Tₚ(n) = b(2ⁿ − 1)

    Para b > 0 y todo entero n ≥ 1. El máximo M no interviene en esta identidad.

    1Caso base n = 1

    El primer bloqueo dura b minutos.

    Tₚ(1) = b = b(2¹ − 1)

    La igualdad se cumple para el primer entero.

    2Hipótesis inductiva n = k

    Supón que para un entero arbitrario k ≥ 1:

    Tₚ(k) = b(2ᵏ − 1)

    Es el total de los primeros k episodios. Aún falta añadir el siguiente bloqueo.

    3Paso inductivo n = k + 1

    ¿Qué término debes sumar para incorporar el episodio k + 1?

    Tₚ(k + 1) = b(2ᵏ − 1) + b · 2ᵏ
    = b(2 · 2ᵏ − 1)
    = b(2ᵏ⁺¹ − 1)

    El caso base y este paso para un k arbitrario demuestran la identidad para todo entero n ≥ 1.

    En el algoritmo, este paso es p += d: conservas el acumulado y añades un término.

    Comprobar 30 episodios no demuestra una identidad para todos los enteros. Esa generalización la justifica la inducción.

    ¿Para quién es SUMA Lab?

    Para estudiantes de Ingeniería Informática que estudian sumatorias, progresiones geométricas e inducción matemática. Primero predices; después experimentas, comparas y justificas.

    Se estudia una IP ficticia: 192.0.2.3. Cada episodio representa un bloqueo ya activado. El acumulado suma únicamente las duraciones de bloqueo; no incluye las pausas entre episodios.

    Duración fija

    dᵢ = b
    T𝒇(n) = nb

    Todos los episodios duran lo mismo. El acumulado crece de forma lineal.

    Duplicación

    dᵢ = b · 2ⁱ⁻¹
    Tₚ(n) = b(2ⁿ − 1)

    Cada bloqueo duplica el anterior. El acumulado sigue una suma geométrica.

    Duplicación con tope

    dᵢ = mín(b · 2ⁱ⁻¹, M)
    Tₘ(n) = ∑ mín(b · 2ⁱ⁻¹, M)

    El máximo M limita cada término. El total puede superar M.

    Condiciones del experimento

    • b y M: de 0,01 a 10 000 minutos, hasta dos decimales.
    • n: un entero de 1 a 30 episodios.
    • M ≥ b; razón geométrica constante de 2.
    • Mismos b y n para comparar las tres políticas.

    Qué permiten concluir los resultados

    Describen un modelo matemático determinista. No miden ataques evitados, eficacia de seguridad ni mejoras de aprendizaje. El recurso no conecta con servidores ni aplica bloqueos reales.
